# Arwign Planners — Keyword Strategy (US & UK)

A beginner-friendly reference for what US/UK buyers actually type, and how to use it
across the site, Etsy, Pinterest and the blog. Digital-planner buyers search by
**format + niche + app** — e.g. "adhd digital planner goodnotes". Match that pattern.

## The 4 building blocks of a buyer keyword
`[niche] + [type] + [format] + [app/size]`
- **niche:** adhd, budget, wellness, meal, student, self-care, habit, monthly…
- **type:** planner, tracker, journal, notebook
- **format:** digital, printable, PDF, undated
- **app/size:** GoodNotes, Notability, iPad, A4, A5, US Letter

## Head terms (high volume, competitive)
digital planner · printable planner · goodnotes planner · budget planner · adhd planner ·
undated digital planner · ipad planner · planner pdf · digital notebook

## On-site titles (✅ already applied to templates)
- **Product `<title>`:** `[Product name] — GoodNotes & Printable PDF · Instant Download | Arwign Planners`
- **Category `<title>`:** `[Category] — Digital & Printable PDF for GoodNotes | Arwign Planners`
- Keep product **descriptions** natural but include: the niche word, "digital planner / printable",
  "PDF", "GoodNotes / Notability", "instant download", "undated".

## Etsy (huge for planners — different SEO than Google)
- **Title:** front-load keywords, up to 140 chars, pipe-separated:
  `ADHD Digital Planner GoodNotes | Undated ADHD Daily Planner PDF | Printable ADHD Planner iPad Notability`
- **Tags (all 13):** use multi-word phrases, no repeats: `adhd planner`, `digital planner`,
  `goodnotes planner`, `adhd daily planner`, `printable planner`, `undated planner`, `ipad planner`,
  `planner pdf`, `adhd journal`, `focus planner`, `productivity planner`, `notability planner`, `adhd adults`.
- Put keywords in the **first sentence** of the description too.

## Pinterest (top traffic source for printables — visual + buyer intent)
- Create a **business account**, enable **Rich Pins**, verify the site.
- Pin **tall images (2:3, 1000×1500)** of each planner with keyword text overlay.
- Board names = keywords: "ADHD Planner", "Budget Planner Printable", "GoodNotes Templates".
- Pin title + description = the long-tail keywords above. Link each pin to its product page.

## Instagram / TikTok
- Short "flip-through" / "plan with me" reels; caption with keywords + link in bio to the shop.

## Blog (free organic traffic → funnels to products)
Write helpful posts targeting informational searches, then link to relevant planners:
1. "How to use a digital planner in GoodNotes (step by step)"
2. "The best ADHD planner setup for adults"
3. "Digital vs printable planners — which is right for you?"
4. "How to budget with a paycheck budget planner"
5. "66-day habit tracker: the science and how to start"

## Priority order for you
1. ✅ On-site titles/canonicals/hreflang (done in code).
2. Submit sitemap in Search Console (done) — then check **Coverage** weekly.
3. Set up **Pinterest** (biggest quick win for printables) + **Etsy** listings using the titles/tags above.
4. Publish 1 blog post/week from the list.
5. Later: Google Ads (US & UK) on high-intent terms once you have conversion data.
